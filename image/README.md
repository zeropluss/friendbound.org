# Image Assets for Friendbound.org

This directory contains all image assets for the website. The following images are referenced in the HTML files:

## Required Images

### Hero Images
- `hero-community.jpg` - Main hero image showing diverse group of people supporting each other
- `friendbound-og-image.jpg` - OpenGraph image for homepage (1200x630px)
- `friendbound-twitter-image.jpg` - Twitter card image for homepage (1200x600px)

### Support Groups
- `support-groups-og.jpg` - OpenGraph image for support groups page
- `support-groups-twitter.jpg` - Twitter card image for support groups page
- `anxiety-support-og.jpg` - OpenGraph image for anxiety support group
- `anxiety-support-twitter.jpg` - Twitter card image for anxiety support group

### Feature Icons
- `support-groups-icon.jpg` - Icon for support groups feature (80x80px)
- `safety-icon.jpg` - Icon for safety and privacy feature (80x80px)
- `resources-icon.jpg` - Icon for professional resources feature (80x80px)

## Image Specifications

### OpenGraph Images
- **Size**: 1200x630 pixels
- **Format**: JPG or PNG
- **File size**: Under 1MB
- **Content**: Should include Friendbound.org branding and relevant imagery

### Twitter Card Images
- **Size**: 1200x600 pixels
- **Format**: JPG or PNG
- **File size**: Under 1MB
- **Content**: Should include Friendbound.org branding and relevant imagery

### Feature Icons
- **Size**: 80x80 pixels
- **Format**: JPG or PNG
- **Style**: Circular, professional, representing the feature concept

### Hero Images
- **Size**: 500x400 pixels (responsive)
- **Format**: JPG
- **Content**: Diverse, inclusive imagery representing mental health support community

## Optimization Guidelines

1. **Compression**: All images should be optimized for web
2. **Alt Text**: All images have descriptive alt text in HTML
3. **Responsive**: Images use responsive sizing with `sizes` attribute
4. **Loading**: Images use `loading="lazy"` for performance
5. **Accessibility**: Alt text describes the image content and purpose

## Placeholder Strategy

Until actual images are created, the website will gracefully handle missing images and display appropriate fallbacks. The alt text ensures accessibility even without images.
