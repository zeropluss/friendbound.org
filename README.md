# Friendbound.org

一个安全、专业的在线心理健康支持社区，为焦虑、抑郁、创伤后应激障碍等心理健康问题提供同伴支持和专业资源。

## 🌟 项目特色

- **安全环境**: 24/7专业监督，确保社区安全
- **专业支持**: 心理健康专业人士参与指导
- **同伴连接**: 与理解您经历的人们建立联系
- **丰富资源**: 专业文章、应对策略、危机帮助
- **包容社区**: 欢迎所有需要心理健康支持的人们

## 📁 项目结构

```
friendbound.org/
├── index.html                 # 主页
├── assets/                    # 静态资源
│   ├── css/                   # 样式文件
│   │   └── main.css          # 主样式表
│   └── images/               # 图片资源
├── support-groups/           # 支持小组页面
├── resources/                # 资源页面
├── events/                   # 活动页面
├── blog/                     # 博客页面
├── about-us/                 # 关于我们
├── trust-safety/             # 信任与安全
├── robots.txt                # 搜索引擎爬虫规则
├── llms.txt                  # AI系统理解文件
├── llms-full.txt             # 详细版AI理解文件
└── sitemap.xml               # 网站地图
```

## 🔧 本地开发

1. 克隆仓库
```bash
git clone git@github.com:CharlieLZ/friendbound.org.git
cd friendbound.org
```

2. 使用本地服务器运行
```bash
# 使用Python
python -m http.server 8000

# 或使用Node.js
npx serve .
```

3. 访问 http://localhost:8000
